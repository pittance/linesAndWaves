This is a set of files that are supposed to be used in Processing

**Installation instructions**

(If not done already) Install Processing and run once to check it's OK & close

There should be a sketchbook folder in your user folder

Copy the _linesAndWaves_ folder into your sketchbook folder, this contains the *.pde files that Processing will use

Open Processing and you should see "linesAndWaves" in your sketchbook

Open this and you should see the code

**Running**

There is no user interface, you'll need to edit the parameters of the script manually

Most of the parameters to change are in the start of the file

If you're happy with your results as they are previewed when you run the script you can use the 'e' key on your keyboard to export a set of files

The set of files will have _numShifts_ copies, each of which is a little different from the previous

This allows you to run them through a pen plotter with different pen colours for interesting moire patterns
